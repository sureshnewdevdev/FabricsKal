# Weekly status lab
Open this folder in VS Code. Read Reusable_Prompts_Context_Tutorial.html in a browser for the full 50-minute lab.

For supported Local chat: invoke /weekly-status from .github/prompts and attach context/week-01.md. Repeat in a new chat with week-02.md without modifying the prompt.

For Agent Host: use the weekly-status skill in .github/skills, confirm discovery, invoke it, and attach the notes. Prompt files are not loaded by Agent Host according to current VS Code documentation. If command names collide, keep only the appropriate format for your chosen session.

Git steps and teammate review are exercises to perform in your own repository; they have not been executed here. No weekly schedule is configured. No Python, Node.js, or additional packages are needed.

Example reports may vary in wording. Validate facts, headings, planned versus completed work, and explicit missing values. See peer-review.md.
